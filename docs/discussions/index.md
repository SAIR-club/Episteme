# Discussions

Planning discussions that shaped Episteme, kept so a decision can be traced back to the conversation
it came from.

- **`raw/`** holds each discussion in full, unedited, one file per discussion, named
  `YYYY-MM-DD-<topic>.md`.
- **This index** lists every file in `raw/`. A discussion is not a decision: whatever it settled is
  recorded in [`../planning/decision-log.md`](../planning/decision-log.md) with this file as its
  source, and whatever it left open goes to
  [`../planning/open-questions.md`](../planning/open-questions.md).
- A raw discussion is a draft, not documentation. Do not link to it from code or from the
  architecture docs; link to the decision or ADR instead.
- Remove anything private (credentials, personal data) before committing a discussion.
